Enrol a passkey

Run this once per device. Each run produces one credential; paste them all into the webauthn_credentials array in tfvars, apply, and this page stops working.

Credential

One element of the webauthn_credentials array. Keep this if you are enrolling a second device — you will need to merge both into one array by hand.

tfvars line

Correct as-is for a single device. For two, put both credential objects in the array before quoting it.

Then

  1. Paste the line into your tfvars and tofu apply.
  2. Remove REGISTRATION_TOKEN from the function's environment. It is dead configuration once credentials exist, but a token left lying around is a token that gets reused.
  3. Load the app and sign in. Then delete this page.
